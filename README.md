# Example Code for the TENO-DeC-A Framework

## Project Description

This repository provides an example implementation of the TENO-DeC-A method proposed in this work, using the Sod shock tube problem as a demonstration case.

The code illustrates the basic implementation procedure of the adaptive space-time consistent high-order TENO-DeC-A framework based on a shock sensor.

This code is intended to demonstrate the core implementation ideas of the proposed method and to serve as a reference for researchers interested in understanding and applying the method.
